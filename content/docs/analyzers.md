An analyser is a connected tool that receives data from Flowintel and sends
results back.

![](/images/flowintel_analyzers.png)

At the moment, only [misp-modules](https://github.com/MISP/misp-modules) is
integrated.

## Step by step

1. Select an input attribute
2. Select the modules to run
3. Enter one or more values
4. Submit

![](/images/analyzer/selection.png)

5. Review the results and move your selection to the dedicated area
6. Continue

![](/images/analyzer/result.png)

7. Choose a case
8. Edit a note or create a new MISP object
9. Submit

![](/images/analyzer/attribution.png)
